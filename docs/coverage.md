# 収録漢字とかな

青磁 0.200の収録漢字は、配布ZIPの `収録漢字.txt` で確認できます。入力する漢字と、そのUnicode符号位置（文字番号）の一覧です。青磁明朝・青磁ゴシック・青磁丸ゴシックのRegularとBold、計6本の収録漢字は共通です。 [青磁 0.200の配布ZIP](https://github.com/metasta/seiji-fonts/releases/tag/v0.200)

| 区分 | 字数 |
| --- | ---: |
| 教育漢字 | 1,026 |
| 教育漢字以外の常用漢字の一部 | 200 |
| 合計 | 1,226 |

## 0.200で収録した範囲

教育漢字は、小学校学習指導要領の学年別漢字配当表（平成29年告示）の全1,026字です。0.100ではこの範囲を収録しました。 [文部科学省「小学校学習指導要領（平成29年告示）解説 国語編」](https://www.mext.go.jp/content/20220606-mxt_kyoiku02-100002607_002.pdf)

0.200で追加したのは、平成22年の常用漢字表から教育漢字を除き、Unicodeの符号位置が小さい順に並べた先頭の200字です。「丈」（U+4E08）から「奔」（U+5954）までで、「僕」「俺」「勘」「償」などを含みます。常用漢字の符号位置の特定には、Unihan 18.0.0の `kJoyoKanji` で値が `2010` の項目を参照しました。 [文化庁「常用漢字表」](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/index.html)・[Unicode Unihanの項目定義](https://www.unicode.org/reports/tr38/tr38-41.html#kJoyoKanji)

## 入力する漢字と表示する形

「国」（U+56FD）を入力すると「國」の字形で表示します。文字コードは入力時のままなので、収録を確かめるときは入力する「国」で一覧を参照します。「國」（U+570B）を直接入力した場合は、青磁 0.200の収録範囲外です。未収録の文字は、アプリやブラウザが別のフォントで表示する場合があります。 [字形の選定と調整](glyph-selection.md)

## ア行エとや行え

ア行エ「𛀀」（U+1B000）とや行え「𛀁」（U+1B001）を6本すべてに収録します。横組み・縦組みともに、1字分の送りは全角です。両字の素材は、青磁明朝がさらら明朝3.000、青磁ゴシックが霧ゴシック4.12です。青磁丸ゴシックでは、霧ゴシックの形に丸みを付けました。 [さらら明朝](https://www.akenotsuki.com/eyeben/fonts/sarara.html)・[霧ゴシック](https://www.akenotsuki.com/eyeben/fonts/kirigo.html)
