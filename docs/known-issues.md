# 既知の表示上の制約

## 連続するダッシュの継ぎ目

0.300では、青磁ゴシックと青磁丸ゴシックのRegular・Boldで、「—」（U+2014）または「―」（U+2015）が3字以上続くときの継ぎ目を、横組み・縦組みともに修正しました。

この修正が反映されるには、連続する記号に同じ書体と書式を指定し、アプリ側でフォントの置換処理が有効である必要があります。Safariで旧版のCSSを指定済みの場合は、配布ZIPにある新版のCSSを選択し、ページを再読み込みしてください。 [macOS版Safariの設定](safari.md)

0.200では、同じダッシュを4字続けると、2字ずつのまとまりの間に隙間が生じる場合がありました。
