# 文脈による字形選択と異体字シーケンス

青磁 0.200では、「弁論・弁別・花弁」の「弁」を、文脈に応じて「辯・辨・瓣」の字形で表示できます。「弁別」を「辨別」の字形で表示した場合も、コピーすると入力時の「弁別」が得られます。以下の対応範囲は、青磁明朝・青磁ゴシック・青磁丸ゴシックのRegularとBoldで共通です。

## 前後の文字に応じた表示

OpenTypeの文脈依存字形機能（`calt`）が有効なアプリでは、前後の文字が登録された規則に一致すると字形が決まります。「花弁」の「弁」は、直前の「花」によって「瓣」の形になります。「弁論」の「辯」は「弁」の既定の字形です。既定の字形は、下表の「通常」欄に示します。 [OpenTypeの `calt` 仕様](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ae#tag-calt)

## 入力した漢字自体の字形を指定する（IVS）

「弁」は通常「辯」、「余」は通常「餘」の字形で表示します。「弁」や「余」自体の形が必要な場合は、表の `弁󠄀` や `余󠄀` をコピーして貼り付けます。漢字とその直後に置く字形指定用の文字（異体字セレクタ）の組を、異体字シーケンス（IVS）と呼びます。上の二例では異体字セレクタはU+E0100です。対応アプリでは、IVSの指定が `calt` より優先します。

### 同音の別字を表示する例

「台頭」を「擡頭」、「台風」を「颱風」の字形で表示する規則もあります。同音の別字による表記は、一部の語に限る補足的な機能です。

### 表の語句で目的の字形が出ないとき

アプリで `calt` を有効にし、表の文字列を同じフォント・書式で入力します。「花 弁」と間に空白を挟むと、「花［弁］」の規則に一致しません。アプリが途中で処理を分ける場合も、前後の文字を同時に参照できず、規則が適用されないことがあります。

表の規則に当てはまる文脈がなく、IVSによる指定もない場合は通常の字形になります。

### 複数の規則が当てはまるとき

対象字の前後に指定された文字数の合計が多い規則を優先し、同数なら登録順で決めます。「天台風」の「台」は「天［台］」と「［台］風」に当てはまります。この場合は先に登録された「天［台］」の規則を適用し、「台」の字形を表示します。
