# 文脈による字形選択と異体字シーケンス

青磁 0.300では、「弁論・弁別・花弁」の「弁」を、文脈に応じて「辯・辨・瓣」の字形で表示できます。「弁別」を「辨別」の字形で表示した場合も、コピーすると入力時の「弁別」が得られます。以下の対応範囲は、青磁明朝・青磁ゴシック・青磁丸ゴシックのRegularとBoldで共通です。

## 前後の文字に応じた表示

OpenTypeの文脈依存字形機能（`calt`）が有効なアプリでは、前後の文字が登録された規則に一致すると字形が決まります。「花弁」の「弁」は、直前の「花」によって「瓣」の形になります。「弁論」の「辯」は「弁」の既定の字形です。既定の字形は、下表の「通常」欄に示します。 [OpenTypeの `calt` 仕様](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ae#tag-calt)

## 入力した漢字自体の字形を指定する（IVS）

「灯」「余」「予」は通常「燈」「餘」「豫」の字形で表示します。「ともしび」の意味で「灯」を、一人称として「余」や「予」を表示したい場合は、下の表から `灯󠄀`・`余󠄀`・`予󠄀` のいずれかをコピーして入力します。

「台台」と「芸芸」では、先頭の字に規則が適用され、2字目も表の「表示字形」になります。

### 同音の別字を表示する例

「台頭」を「擡頭」、「台風」を「颱風」の字形で表示する規則もあります。同音の別字による表記は、一部の語に限る補足的な機能です。

### 表の語句で目的の字形が出ないとき

アプリで `calt` を有効にし、表の文字列を同じフォント・書式で入力します。「花 弁」と間に空白を挟むと、「花弁」の規則に一致しません。

行ごとに字形を決めるアプリでは、「花弁」が「花」と「弁」の間で改行されると、「弁」は通常の「辯」の字形になります。画面幅や文字サイズで自動改行の位置が変化するため、同じ入力でも字形が異なる場合があります。

適用できる文脈規則もIVSの指定もない場合は、通常の字形になります。改行位置による字形の差を避けるには、収録済みの漢字を直接入力するか、対応するIVSを入力します。0.300では置換先の一部が直接入力の対象外です。入力できる漢字は配布ZIPの `収録漢字.txt` で確認できます。

### 複数の規則が当てはまるとき

対象字の前後に指定した文字数の合計が多い規則を優先し、同数なら登録順で決めます。「天台風」の「台」には、直前の「天」によって「天台」の規則が、直後の「風」によって「台風」の規則が当てはまります。この場合は先に登録された「天台」の規則を適用し、「台」の字形を表示します。
